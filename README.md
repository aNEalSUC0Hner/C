## Tentang proyek

![Tangkapan layar aplikasi](https://cdn.example.dev/shots/rose-app.png)

Pengguna mengunggah sebuah foto atau mengambil gambar langsung dari kamera. Setelah diproses, layar menampilkan jumlah mawar yang ditemukan beserta rata-rata tingkat keyakinan model. Hasilnya bisa diunduh sebagai gambar, atau dijadikan laporan yang juga bisa diunduh.

Aplikasi ini dikerjakan oleh empat mahasiswa sebagai proyek akhir mata kuliah.

## Memulai

### Yang perlu disiapkan

* Python 3.8 ke atas

  Unduh dari situs resmi Python.

* Pustaka yang tercantum pada berkas kebutuhan proyek

  Pasang sekaligus dengan satu perintah pip.

### Menjalankan

1. Salin repositori ke mesin lokal
2. Buat dan aktifkan lingkungan virtual
3. Pasang dependensi
4. Jalankan migrasi basis data
5. Nyalakan server pengembangan lalu buka alamat lokal di peramban

Setelah satu gambar selesai diproses, kembali ke halaman utama untuk menguji gambar lain.
